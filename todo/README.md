# Todo list

Open `index.html` in a browser. Add, edit, or delete tasks. Each task has a Low, Medium, or High priority; new tasks default to Medium, and priority can be changed when editing. Tasks remain in insertion order. Filter tasks by text using a case-insensitive substring search; leading and trailing search spaces are ignored. Clear the search to show every task. Editing or deleting a filtered task changes the original task. Tasks are stored in memory and reset on reload.
